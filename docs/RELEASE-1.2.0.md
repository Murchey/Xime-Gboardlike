# XimeGboard 1.2.0 更新说明

> 这一版把「用户词库」真正做成了可以管理的一本，补齐了长按、符号页、数字键盘的交互细节，设置页也换成了与 Gboard 新版一致的卡片风格。

## ✨ 新增

### 词库本管理
- **用户词库 → 顶栏「书本」图标**：查看本机所有词库、新建、删除、指定「当前记录词库」。
- 指定后**所有方案**（含导入与未启用方案）都会把新词写进同一本，不再按方案各记一份。
- 升级后首次启动会自动把原有的多本 `userdb` 合并进统一词库（与 PC 端同一套合并语义：同词条取较大频率），旧库文件保留，可随时导出文本码表。
- 「记录为多本词库」开关仍保留（默认关闭），本版暂不生效。

### 键盘交互
- 字母长按补全**大小写 + 注音/变音变体**（与 fcitx5-android 同源），Gboard / fcitx5 两套符号排布都生效；合并键长按仍是组内字母。
- 长按气泡**默认选中键面角标符号**；两行候选面板支持**向下滑直接选第二行**。
- shift 键三态重绘：未按为空心箭头，单击填充实心，双击锁定并在箭头下方加一根横条；取消激活态的键帽高亮。
- **符号页返回直达字母主键盘**（设置 → 键盘偏好 可关闭「符号键盘取消二次返回」）。
- 数字输入框直接进入的数字键盘改走主键盘分支，**沿用底部留白**，不再贴屏幕底边。

### 设置与部署
- 部署时显示**不可取消的进度窗口**（首次编译可能几十秒，期间不会以为卡死）。
- 异体键盘（14/17/18 键）部署**只保留最近三次**，更早的整套（方案文件 + 编译产物）自动清理；清理未启用编译缓存时也会删掉未使用的异体键盘。
- 设置页改用 **Gboard 新版大圆角卡片**：卡片内行分隔线、蓝灰配色、单色灰图标、灰色分组小标题、24dp 圆角；输入测试框同款卡片。

## 🐛 修复
- 语音识别**只有第一次长按可用**（识别中再次按下先收尾、再进入新一轮）。
- 切换「符号提示排布」后角标与上滑值不更新（缓存按新风格重算）。
- 修改**键序 / 键数**并重新部署后，当前方案不更新、键盘仍是旧布局。
- 异体键盘允许从导入方案派生（现在**仅允许内置基础方案**派生）。
- 数字/符号键盘与主键盘**底部留白不一致**。
- m/v/n/l/k/y/u/i/o/p 等键长按默认选中的不是角标符号。
- 两行长按面板只能向上滑才能选到第二行。
- 所有内置主题默认开启「强调第一个候选」。
- fcitx5 风格下 f 的长按符号不是半角「-」。

## ⚠️ 升级须知
1. **首次启动会合并词库**（一次性，视旧库大小可能耗时数秒到十几秒）；旧 `<词典名>.userdb` 不会被删除。
2. 合并只迁移词条，不迁移按键习惯；切换「当前记录词库」后会触发一次部署，**期间请勿退出设置**。
3. 异体键盘只保留最近三次部署：在多套 14/17/18 键配置之间来回切时，较早的那套会被自动删除（切回去会重新生成并重新编译）。
4. 若你之前手动改过 `<方案>.custom.yaml` 里的 `translator/user_dict`，本版会按「当前记录词库」统一改写；想保留旧配置请先导出词库文本码表。
